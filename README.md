# Proyecto Hábitos Atómicos

Aplicación web para gestionar hábitos desarrollada con Express.js (Backend) y Next.js (Frontend).

## Estructura
- `/backend`: API REST con Node.js, Express y MongoDB.
- `/frontend`: Interfaz de usuario con Next.js y Redux.

## Instrucciones de ejecución

### 1. Levantar el Backend
1. Abrir una terminal y navegar a la carpeta: `cd backend`
2. Instalar dependencias: `npm install`
3. Crear archivo `.env` con las variables `PORT` y `MONGO_URI`.
4. Iniciar servidor: `npm run dev`

### 2. Levantar el Frontend
1. Abrir otra terminal y navegar a la carpeta: `cd frontend`
2. Instalar dependencias: `npm install`
3. Iniciar aplicación: `npm run dev`
4. Abrir en el navegador: `http://localhost:3000`
